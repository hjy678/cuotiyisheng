# 🩺 家庭错题医生（单文件离线版）

一个零依赖、可离线运行的「家庭错题管理系统」单文件网页。拍照/粘贴录入错题，AI 错因分析 + 举一反三，间隔复习(SRS)，知识点掌握度看板，智能组卷，薄弱点导出。数据只存在你本机浏览器，不上传任何服务器。

## 怎么用
- **本地**：双击 `index.html`（或 `错题医生.html`）用浏览器打开即可。
- **微信/手机**：部署到 GitHub Pages 后，把 `https://你的用户名.github.io/仓库名` 发到微信，点开即可使用（微信内置浏览器可正常打开，不被拦截）。也可直接把 `index.html` 文件发到微信文件传输助手，用手机浏览器打开。

## 核心功能
1. 📷 录入：拍照 / 粘贴截图(Ctrl+V) / 拖拽；图片压小后仅存本机。
2. 🤖 AI 分析（可选）：在「⚙设置」填一个 OpenAI 兼容 API（地址/模型/Key）后，点「AI 分析」自动出 错因 + 解题步骤 + 苏格拉底引导 + 举一反三。不填也能纯手动用。
3. 📊 掌握度看板：按知识点聚合，红=待掌握 黄=一般 绿=已掌握。
4. 🔁 间隔复习：对→1/2/4/7/15/30 天拉长，错→明天重来，自动提醒今日待复习。
5. 📝 智能组卷：按今日/薄弱/全部组卷，答案不进 DOM 防作弊，可打印。
6. 📉 薄弱点报告：导出 CSV / 可打印 PDF，发老师或贴墙。
7. 👧 多学生多科目：顶部切换，数据互相隔离。

## 预置知识点标签
录入时按科目显示可点选标签，覆盖：
- 三年级 PEP：数学 / 英语 / 语文（三上三下）
- 荣波（四年级）：数学 / 语文 / 英语
- 荣海：数学 / 语文 / 英语

## 可选 AI 配置（⚙设置）
填三项即可启用 AI 增强（仅在你点击「AI 分析 / 组卷」时联网，且**只发送题目文字，不上传图片**）：
- API 地址（OpenAI 兼容）：如 `https://api.deepseek.com/v1/chat/completions`
- 模型名：如 `deepseek-chat`
- API Key：去对应平台注册获取

## 隐私
所有错题、图片、设置都只存在浏览器 `localStorage`，不联网、不上传。可用「⬇导出/备份」导出 JSON 或 CSV 备份。
